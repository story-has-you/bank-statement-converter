# 产品边界

## 当前范围

产品目前只包含以下四项功能：

网站界面支持英语、简体中文、日语、韩语、德语、法语、西班牙语、巴西葡萄牙语、意大利语、荷兰语、印地语和印度尼西亚语，共 12 种语言。语言选择只影响界面、错误提示、风险原因、metadata 和下载结果的文字，不改变额度、价格、支付服务或法律管辖区。

1. **登录**：通过 Supabase Auth 提供 Google 登录和登录状态管理；匿名用户也可使用免费转换额度。
2. **PDF 转 Excel**：用户上传银行流水 PDF，系统解析文件并生成 Excel。符合输入条件的银行版式均可尝试转换；只有经过脱敏样本逐行核对的具体版式才称为“已验证”，不据此宣称支持该银行的所有账单。PDF 仅用于本次转换，不保存到系统的数据库、对象存储或持久化文件历史；multipart 解析的短暂临时文件不提供再次下载能力，处理结束后清理。
3. **下载结果**：用户下载本次转换生成的 Excel，也可选择 CSV、JSON、Markdown、TSV 或 HTML。所有格式由浏览器根据同一份最终解析结果生成，系统不保存导出文件；离开本次转换流程后，不提供历史文件下载。
4. **订阅**：匿名用户每天累计可转换 1 页 PDF，已登录的免费用户每天累计可转换 5 页 PDF；订阅会员通过 Creem 按月自动续费，当前提供 standard（19.90 USD/月）、professional（49.90 USD/月）和 enterprise（79.90 USD/月）三个档位，额度分别为每个 Creem 计费周期 500、1000 和 2000 页。价格、免费额度、订阅额度与 Qwen 回退资格统一配置在 `src/config/plans.ts`，页面展示与服务端额度校验读取同一配置。

订阅业务通过通用计费模块与支付渠道适配器集成，当前仅开放 Creem。取消自动续费后的权益保留至本期结束，结束前不能重新订阅。

## 核心流程与数据边界

系统按匿名、已登录免费用户或订阅会员的使用资格确认可用额度；用户上传 PDF，等待解析和生成 Excel，然后下载结果。转换失败时应告知用户失败，且不提供无效文件。

- PDF 和各格式导出文件只在完成本次转换及下载所必需的处理过程中使用；不写入持久化数据库、对象存储或文件历史。处理结束后不保留可供再次下载的文件。
- 浏览器会话存储临时保存提取结果，用于当前预览和下载流程；这不属于服务端持久化文件历史。
- 用户可以在最终结果中为各表手动选择商户名称或描述列，在本次文件内跨表勾选别名、统一命名、重新命名和撤销。仅按原始文本精确分组，不自动推断商户身份；原始文字、交易顺序、来源及提取风险不变。Python 与大模型的最终结果共用此处理，不额外调用模型。
- 商户映射随本次结果临时保存在当前标签页会话中，刷新可恢复，重新转换或清理结果时一起清除；不保存到服务端，不跨文件复用。浏览器保存失败时提示用户，当前页面仍可预览和导出。
- 为实现登录、订阅、每日额度及解析故障排查，可以保存必要的用户身份、订阅状态、使用量、计费及解析运维元数据；这些数据不应包含 PDF 原文、解析出的流水明细或导出文件内容。
- 登录用户开始解析后，可以保存账号 ID、邮箱快照、记录时间、最后选择的解析方式、成功/部分成功/失败/取消状态及安全的错误原因。匿名请求、输入校验失败及额度预检查失败不产生解析记录。解析记录不包含文件名、原始异常文本或模型输出；删除账号时级联清除关联记录。
- 不提供文件历史、转换结果归档、云端文件管理或历史结果重新下载。

## 转换契约

- 单文件最多 4 MB、50 页。匿名、免费和 Standard 只接受有文字层的银行流水 PDF；Professional 和 Enterprise 在有效使用资格内优先使用 Python，服务不可用或无法产出可核对交易时回退至千问 Qwen3.8 Flash，可尝试扫描版 PDF。密码保护、无效或超限文件直接拒绝。Python 已有可用部分结果时不触发大模型回退。
- 只提取可确认的交易明细；已识别出的非交易内容可跳过。相同表头可跨原始页合并为一个逻辑表，不同表头保持为不同逻辑表。结果页数与来源页码均指原始 PDF 页。
- Excel 按逻辑表分别建立工作表，尽量保留原始表头和单元格文本；每行附状态、具体风险原因、原始页码及页内起始行。无法对应到交易行的失败页信息放在首个工作表顶部。
- CSV、TSV 每个逻辑表下载一个文件，采用 UTF-8 BOM；批量下载后提供逐表下载入口，以便浏览器限制多文件下载时使用；原始列后附行级风险与来源字段，以及页面风险、表格提示列，空表有风险时输出流水字段为空的提示记录。JSON 完整保留 `ParseResponse`，包含原始状态、风险代码及参数、摘要和来源信息；Markdown、HTML 各用一个文件呈现全部表格及提示。导出保留单元格原始文本，JSON 保留空值。
- 行级状态为 `OK`、`DISCREPANCY`、`UNVERIFIABLE`：有日期、描述和金额证据但与其他证据矛盾的行标为 `DISCREPANCY`；缺少关键证据或无法可靠配列的行标为 `UNVERIFIABLE`，两类问题并存时以后者为准。风险代码保持稳定，网页和表格类导出格式提供本地化的具体原因，JSON 保留机器可读的风险代码及参数。
- 至少确认一个商户别名后，预览和表格类导出格式增加标准商户名及归一化状态；未分配行名称留空，状态为未归一化。JSON 在原有每行字段之外增加 `merchantName` 和 `merchantNormalizationStatus`，未分配名称为 `null`，状态为 `confirmed` 或 `unassigned`。这些是浏览器导出字段，不改变解析 API；撤销全部映射后恢复原有格式。风险筛选不改变归一化及导出的完整交易范围。
- 至少有一行可核对交易时，其他行或页面无法可靠核对仍可提供带风险标注的部分结果；没有任何可核对交易则不开放任何格式下载。`SUCCESS` 仅表示解析器未检测到风险，不保证与原始 PDF 完全一致或零遗漏。
- “已验证版式”需要用脱敏样本逐行核对交易数量、日期、描述、金额及方向；验证结论只适用于被核对的版式变体。尚不公布通用银行支持名单或量化准确率。

## 待确定的产品规则

- 具体已验证版式清单、更多脱敏验收样本、统计准确率的评价标准和公开表述。
- 日额度按 UTC 重置，匿名使用量按 HttpOnly Cookie 身份累计，匿名额度不迁移到登录账号；失败转换不扣减额度，partial 结果按 PDF 页数累计。当前用量只保留每个身份的一行，不保存历史用量记录。
- 订阅套餐、计费周期、会员额度和支付服务商已确定；Creem 按月自动续费，生产环境配置和真实支付验收仍需单独确认。
- Python 负责常规解析；Next.js 负责千问回退、统一 JSON 校验和额度扣减。高阶套餐回退时将 PDF 发送至千问，适用其服务条款及隐私政策。本网站不持久化转换内容，不额外承诺供应商的数据保存政策。

在更多版式验收完成前，不承诺通用银行支持名单或准确率数字。扫描件仅开放给 Professional 和 Enterprise，真实模型效果须用脱敏样本核对。

## 大模型与流式结果

- 千问回退在 Next.js 服务端使用 OpenAI 官方 SDK 的 Chat Completions 完成；密钥为仅服务端使用的 `QWEN_API_KEY`。千问 PDF 理解不支持 Responses API，因此不通过该接口传 PDF。
- 千问结果沿用 Python 的 `ParseResponse` 契约，扣减页数以服务返回的 PDF 解析用量为准，覆盖模型自行生成的页数。权威页数缺失、超限、结果无效或无可核对交易时不扣额度。
- 结果页可逐步显示表头和完整交易行，这些是生成中的临时预览；完整结果通过校验且未超过请求开始时的剩余额度后即可下载，额度在响应结束后异步扣减。最终页数与来源位置均使用原始 PDF 的页面范围，并以千问返回的解析页数校验。
- 生成中的结果仅在内存中使用，完成后才进入当前浏览器会话交接；离开、切换语言或刷新不恢复生成任务。解析失败不扣额度，已成功完成的扣减不因后续连接或浏览器存储失败自动回滚。

- Qwen 显式关闭思考模式。异步扣额只调用一次原子 RPC；后台拒绝或写入失败只记录错误码日志，不撤回已返回结果、不自动重试。并发请求的剩余额度快照可能过期，后台任务不提供持久化重试保证。
- 解析记录通过独立的 `after()` 任务异步写入，调度或写入失败不影响转换、下载或额度任务，不自动重试。Python 的失败原因与转换最终失败码分开保存；大模型回退原因区分解析问题、服务故障、响应异常与未知原因，只记录已有证据。记录采用尽力写入，进程退出或平台超时可能导致缺失，不提供持久任务或补偿保证。

## Creem 支付渠道

订阅支持 Creem。三个套餐价格、页数和 AI 解析权益继续由现有配置决定。Creem 首次付款和续费仅由已验签且核实远端交易的事件确认；取消自动续费保留已付周期，扣款失败不延长账期。此次不增加试用、客户门户、退款、套餐升级或文件存储功能。测试环境接入不代表正式支付已启用。

优惠券在 Creem 托管结账页输入，支持百分比、固定金额和全额抵扣。优惠券抵扣不属于试用；全额抵扣仍需核实渠道已付款交易、身份和账期。账户订阅记录显示首次实付，使用优惠券时同时显示原价、优惠金额及优惠券标记，不公开券码；历史记录不推测或回填优惠。

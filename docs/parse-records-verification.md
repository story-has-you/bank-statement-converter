# 解析记录交付与验收

先由管理员执行 `supabase/migrations/20261011105727_create_conversion_parse_records.sql`，再发布代码。迁移包含事务、表及全部 10 个字段的中文注释、CHECK 约束、外键、索引、RLS 与最小权限；不需要客户端 RLS 策略。

建表后执行 `supabase/verification/conversion_parse_records.sql`。这是只读验收 SQL，检查结构、注释与权限，最后只查询记录聚合计数，不显示用户 ID 或邮箱。`anon` 和 `authenticated` 无表及序列权限；`service_role` 仅有表查询、插入和序列 USAGE 权限。

## 转换场景

使用测试账号和脱敏样本，在已启动的 3000/8000 服务或测试部署上验收；等待响应结束后的后台写入，再通过聚合查询检查数量变化。每个登录用户请求最多新增一条记录，Python 到千问的回退不拆成两条。JSON 和 SSE 两种响应均需验收。

| 场景                                       | 预期记录                                                           |
| ------------------------------------------ | ------------------------------------------------------------------ |
| Python 成功                                | code / success；两个 Python 原因字段、回退分类和最终错误均为空     |
| Python 可用部分结果                        | code / partial；不调用千问，原因字段为空                           |
| Python 失败且无回退资格                    | code / failed；保存 Python 原因及最终错误，回退分类为空            |
| Python 失败后千问成功或部分成功            | llm / success 或 partial；保留 Python 原因及回退分类，最终错误为空 |
| Python 失败后千问失败                      | llm / failed；保留 Python 原因，最终错误为千问稳定错误码           |
| Python 超时或服务不可用后回退              | llm；回退分类为 service，不描述为 PDF 版式问题                     |
| Python 响应无效后回退                      | llm；回退分类为 response                                           |
| 未知 Python 错误后回退                     | llm；Python 错误码 UNKNOWN，回退分类 unknown，不保存任意上游文本   |
| 解析中取消                                 | cancelled；保留已发生的 Python 失败和回退信息，最终错误为空        |
| 解析后超过剩余额度或结果大小限制           | failed；保留最后选择的方式、已有 Python 原因及最终拒绝码           |
| 匿名、输入校验失败或额度预检查失败         | 不新增记录                                                         |
| 记录任务调度失败、数据库无权限或暂时不可用 | 转换结果、下载及独立额度任务保持原有行为；只输出安全错误码日志     |

测试数据库错误时只在隔离测试环境阻断记录表写入，避免同时破坏认证、订阅和额度所使用的数据库连接。检查后台日志不包含邮箱、用户 ID、文件名、异常详情或交易内容。写入不自动重试；无法从尽力写入日志推断所有历史请求均已留存。

## 生命周期与边界

在测试环境删除测试账号，确认外键级联删除其解析记录。身份和邮箱快照应与服务端认证账号一致，不能被客户端提交字段覆盖。记录创建时间是数据库写入时间，不是请求开始时间；状态表示转换结局，不表示下载完成或后台扣额结果。进程退出或平台超时可能导致记录缺失。

迁移和真实 Supabase、Python、千问请求需实际执行后才可称为已验收；本交付不执行真实数据库变更或外部模型调用。

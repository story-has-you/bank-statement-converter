# 解析记录只保存运维元数据并异步写入

为排查登录用户的解析失败和大模型回退，保存每次解析尝试的账号 ID、邮箱快照、写入时间、最后选择的解析方式、结局及稳定错误码和固定原因说明。不保存文件名、PDF、流水明细、模型输出或原始异常文本，不新增文件历史或历史下载；删除账号时级联删除关联记录。

记录在统一结束路径中通过独立的 Next.js `after()` 任务写入，与额度任务分别处理异常，避免数据库等待或记录故障影响解析、流式输出和下载。匿名请求及开始解析前的输入或额度拒绝不记录；Python 部分结果仍不回退。Python 阶段错误与最终转换错误分别保留，避免将服务故障误判为文件解析能力不足。

这是尽力写入的运维记录：不自动重试，不提供持久任务或补偿，进程退出或平台超时可能导致记录缺失。相比必须同步写入成功才交付结果，本方案优先保证转换流程；状态描述转换结局，不保证下载完成或后台额度扣减成功。表只向服务端开放，客户端无法查询、写入或修改记录。

# 商户别名归一化验收记录

日期：2026-10-16。本次在已有 `http://localhost:3000` 服务中通过 agent-browser 操作实际结果页、下载并读取文件，使用合成数据，没有调用真实解析器、模型或扣额接口。

## 实现范围

- 每张表手动选择原始名称或描述列，整个文件按原文精确分组；搜索、每页 50 个名称、跨表批量确认、改名、撤销和清空。
- 原始解析结果保持不变。预览和导出从当前映射派生标准商户名及独立的归一化状态；风险筛选仅影响预览。
- 映射与本次转换结果一起临时保存到当前标签页会话，刷新恢复；新转换不继承。服务端 API、模型输出和数据库均未改动。

## 已验证

| 场景                                                  | 结果                                                                                                                      |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 三表、65 行，其中两表参与整理，三种商户别名共六笔交易 | 一次确认同步更新两表；跳过的第三表保持未归一化                                                                            |
| 大小写差异、空字符串、纯空白及 null                   | 大小写不同的名称独立分组；空内容不进入列表；原始单元格保留                                                                |
| 超过 50 个名称、搜索及跨搜索选择                      | 首屏 50 个、第二页 8 个；搜索重置分页；不同搜索中勾选的名称可一起应用                                                     |
| 空白标准名称、首尾空格                                | 空白提交显示错误，不应用；有效名称去除首尾空格                                                                            |
| 风险行、风险筛选                                      | DISCREPANCY 和 UNVERIFIABLE 行可整理；风险数量与来源不变；筛选不改变批量应用或导出范围                                    |
| 改名、撤销、清空                                      | 改名应用到全部相关行；撤销跨表生效；清空保留来源列选择并恢复原有导出字段                                                  |
| 更换已确认的来源列                                    | 取消时保留原列及映射；确认时只清除该表映射，其他表保留                                                                    |
| 刷新和旧会话                                          | 刷新恢复来源列及映射；没有归一化字段的旧结果正常显示                                                                      |
| sessionStorage 写入失败                               | 显示保存失败提示；当前修改仍可预览和下载，实际 JSON 包含未保存的最新名称                                                  |
| Excel、CSV、TSV、JSON、Markdown、HTML                 | 实际下载并核对原始文字、商户名、状态、风险和来源；Excel 三个工作表及逐表 CSV/TSV 行数正确                                 |
| 下载缓存                                              | 修改名称后旧的逐表下载入口消失，重新生成并下载的文件使用最新名称                                                          |
| 特殊文本                                              | 原文含逗号、引号和换行可保留；标准名称中的 HTML 和 Markdown 特殊字符正确转义；constructor、**proto** 可作为普通别名处理   |
| 流式预览和再次转换                                    | 在本地拦截 `/api/convert` 返回合成 SSE；生成中不显示整理功能，complete 后可批量命名；再次转换清除映射且结果不继承额外字段 |
| 空结果与失败结果                                      | 不开放商户整理及下载，原有风险显示正常                                                                                    |
| 窄屏                                                  | 390px 视口下页面宽度为 390px，表格在自身容器内滚动，操作按钮可换行                                                        |

# 产品边界

## 当前范围

产品目前只包含以下四项功能：

网站界面支持英语、简体中文、日语、韩语、德语、法语和西班牙语。语言选择只影响界面、错误提示、风险原因、metadata 和下载结果的文字，不改变额度、价格、支付服务或法律管辖区。

1. **登录**：通过 Supabase Auth 提供 Google 登录和登录状态管理；匿名用户也可使用免费转换额度。
2. **PDF 转 Excel**：用户上传银行流水 PDF，系统解析文件并生成 Excel。符合输入条件的银行版式均可尝试转换；只有经过脱敏样本逐行核对的具体版式才称为“已验证”，不据此宣称支持该银行的所有账单。PDF 仅用于本次转换，不保存到系统的数据库或文件存储。
3. **下载 Excel**：用户下载本次转换生成的 Excel。系统不保存生成的 Excel；离开本次转换流程后，不提供历史文件下载。
4. **订阅**：匿名用户每天累计可转换 1 页 PDF，已登录的免费用户每天累计可转换 5 页 PDF；订阅会员通过 PayPal 按月自动续费，当前提供 standard（30 USD/月）、professional（60 USD/月）和 enterprise（99 USD/月）三个档位，额度分别为每个 PayPal 计费周期 400、1000 和 4000 页。

## 核心流程与数据边界

系统按匿名、已登录免费用户或订阅会员的使用资格确认可用额度；用户上传 PDF，等待解析和生成 Excel，然后下载结果。转换失败时应告知用户失败，且不提供无效文件。

- PDF 和 Excel 只在完成本次转换及下载所必需的处理过程中使用；不写入持久化数据库、对象存储或文件历史。处理结束后不保留可供再次下载的文件。
- 为实现登录、订阅和每日额度，可以保存必要的用户身份、订阅状态、使用量与计费元数据；这些数据不应包含 PDF 原文、解析出的流水明细或 Excel 内容。
- 不提供文件历史、转换结果归档、云端文件管理或历史结果重新下载。

## 转换契约

- 当前只接受有文字层的银行流水 PDF，单文件最多 20 MB、50 个原始 PDF 页。扫描图片、密码保护、无可用文字或超限文件直接拒绝。
- 只提取可确认的交易明细；已识别出的非交易内容可跳过。相同表头可跨原始页合并为一个逻辑表，不同表头保持为不同逻辑表。结果页数与来源页码均指原始 PDF 页。
- Excel 按逻辑表分别建立工作表，尽量保留原始表头和单元格文本；每行附状态、具体风险原因、原始页码及页内起始行。无法对应到交易行的失败页信息放在首个工作表顶部。
- 行级状态为 `OK`、`DISCREPANCY`、`UNVERIFIABLE`：有日期、描述和金额证据但与其他证据矛盾的行标为 `DISCREPANCY`；缺少关键证据或无法可靠配列的行标为 `UNVERIFIABLE`，两类问题并存时以后者为准。风险代码保持稳定，网页与 Excel 提供本地化的具体原因。
- 至少有一行可核对交易时，其他行或页面无法可靠核对仍可提供带风险标注的部分结果；没有任何可核对交易则不生成 Excel。`SUCCESS` 仅表示解析器未检测到风险，不保证与原始 PDF 完全一致或零遗漏。
- “已验证版式”需要用脱敏样本逐行核对交易数量、日期、描述、金额及方向；验证结论只适用于被核对的版式变体。尚不公布通用银行支持名单或量化准确率。

## 待确定的产品规则

- 具体已验证版式清单、更多脱敏验收样本、统计准确率的评价标准和公开表述。
- 日额度按 UTC 重置，匿名使用量按 HttpOnly Cookie 身份累计，匿名额度不迁移到登录账号；失败转换不扣减额度，partial 结果按 PDF 页数累计。当前用量只保留每个身份的一行，不保存历史用量记录。
- 订阅套餐、计费周期和支付服务商已确定为 PayPal Sandbox 自动续费；生产环境配置和具体会员额度仍待确定。
- 转换处理的位置与所用服务；选型时必须满足上述不保存 PDF 和 Excel 的边界。

在具体额度和更多版式验收完成前，不承诺通用银行支持名单、准确率数字或会员额度；当前不支持扫描件。

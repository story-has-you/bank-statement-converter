# 产品边界

## 当前范围

产品目前只包含以下四项功能：

1. **登录**：集成 Supabase，提供用户登录和登录状态管理。具体登录方式待确定。
2. **PDF 转 Excel**：已登录用户上传银行流水 PDF，系统解析文件并生成 Excel。PDF 仅用于本次转换，不保存到系统的数据库或文件存储。
3. **下载 Excel**：用户下载本次转换生成的 Excel。系统不保存生成的 Excel；离开本次转换流程后，不提供历史文件下载。
4. **订阅**：提供订阅制，并根据订阅状态控制转换功能的使用资格。套餐、价格、额度、试用规则和支付服务商待确定。

## 核心流程与数据边界

用户登录后，确认订阅资格，上传 PDF，等待解析和生成 Excel，然后下载结果。转换失败时应告知用户失败，且不提供无效文件。

- PDF 和 Excel 只在完成本次转换及下载所必需的处理过程中使用；不写入持久化数据库、对象存储或文件历史。处理结束后不保留可供再次下载的文件。
- 为实现登录和订阅，可以保存必要的用户身份、订阅状态与计费元数据；这些数据不应包含 PDF 原文、解析出的流水明细或 Excel 内容。
- 不提供文件历史、转换结果归档、云端文件管理或历史结果重新下载。

## 待确定的产品规则

- 支持哪些银行流水 PDF、扫描件及文件大小上限，以及转换结果的 Excel 字段和格式。
- 解析失败或部分识别成功时的提示与处理方式。
- Supabase 登录方式，以及订阅套餐、计费周期、额度和支付服务商。
- 转换处理的位置与所用服务；选型时必须满足上述不保存 PDF 和 Excel 的边界。

在这些规则明确前，不将某种银行格式、识别准确率、支付渠道或套餐权益视为已承诺功能。

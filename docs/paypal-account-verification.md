# 账户页与 PayPal Sandbox 验收

本功能不需要数据库迁移。现有 `billing_subscriptions` 必须包含金额、币种、账期和最近事件字段。

## 回调配置

在同一个 PayPal Sandbox REST 应用的 Webhook 配置中确认订阅以下事件，监听地址使用部署后的 `/api/paypal/webhooks`：

- `BILLING.SUBSCRIPTION.ACTIVATED`
- `BILLING.SUBSCRIPTION.CANCELLED`
- `PAYMENT.SALE.COMPLETED`

`PAYPAL_WEBHOOK_ID` 必须与该配置匹配；监听地址必须允许 PayPal 访问。不要把生产订阅用于验收。

## 界面与权限

- Google 登录后，头像打开当前语言的 `/account`；无头像或图片加载失败时显示默认用户图标。未登录访问账户页跳转当前语言首页。
- 七种语言、浅色和深色主题、手机宽度下检查账户页。订阅表格可横向滚动，取消对话框可通过键盘操作。
- 空订阅显示免费套餐；旧记录缺失金额或日期显示暂无。模拟读取失败时，额度显示暂不可用。
- 核对账户页页数与转换接口一致；过期使用量不计入新周期；额度为零时进度条为零。
- 未登录访问账户接口返回 401，读取响应为 `private, no-store`；取消请求必须来自本站且属于当前用户。跨账户订阅 ID 返回 404。

## 取消与续费

- 用 Sandbox 用户确认取消：PayPal 成功前不可显示已停止续费。PayPal 失败时数据库和额度保持原状，允许重试。
- PayPal 已取消但数据库仍激活时，账户显示等待同步；重复请求不再调用取消。页面最多轮询十五次，超时后可手动检查。
- 真实取消回调必须通过签名验证和 PayPal 身份、状态核对，才修改已有记录为 `CANCELLED`。取消接口和读取接口不得修改订阅状态。
- 核对取消前后的账期和已用页数一致；截止前可继续使用剩余额度，截止时恢复免费日额度。重新订阅后只使用新的激活订阅额度。
- 实际续费付款成功后，核对同一订阅记录进入新账期，使用量随原有周期规则重置。首次付款及重复事件不重复重置额度。
- 重送事件并交错发送续费、取消、激活事件，确认迟到付款或激活事件不能恢复已取消状态。并发冲突、续费先于激活入库、PayPal 账期未就绪时应返回 502，允许 PayPal 重试。

本地 lint、类型检查和构建不证明上述 PayPal、数据库及浏览器场景已通过。完成 Sandbox 验收后再确认停止下期扣费和回调入库行为。
